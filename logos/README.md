# Logo's

Zet hier een logo neer als `<domein>.png`, dan gebruikt de pagina dat in plaats van een externe dienst. Bijvoorbeeld:

- `marktplaats.nl.png`
- `2dehands.be.png`
- `2ememain.be.png`
- `markt.de.png`
- `quoka.de.png`

Een vierkant plaatje van 32 of 64 pixels is genoeg, bijvoorbeeld het icoontje uit het tabblad van de site.

De logo's van eBay, Facebook en Kleinanzeigen zitten al in `index.html`. Ze komen uit [Simple Icons](https://simpleicons.org/), die onder de CC0-licentie vallen.
